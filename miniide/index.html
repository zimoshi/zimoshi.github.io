MiniIDE

A beautifully compact, Python-powered IDE with OpenAI integration and terminal support — built by Zimoshi.

🚀 Features

  • Tabbed code editor with Python syntax highlighting
  • Run and debug Python code with a built-in terminal
  • AI Assistant (GPT-4o) embedded directly into your workspace
  • Outline view for navigating classes and functions
  • Dark mode and folder explorer support

📦 Installation

git clone https://github.com/zimoshi/MiniIDE.git
cd MiniIDE
python3 minieditor.py

🧠 Powered by

  • tkinter for GUI
  • pygments for syntax highlighting
  • openai for AI chat
