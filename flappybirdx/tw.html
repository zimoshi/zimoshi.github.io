FlappyBirdX

FlappyBirdX 是一款為 macOS 打造的極簡 Flappy Bird 桌面遊戲。
使用 Python + PyInstaller 打包，無需額外設定，下載即可遊玩。

🚀 一行指令安裝

curl https://zimoshi.github.io/flappybirdx.sh | bash

執行完成後，FlappyBirdX 會自動安裝至：
/Applications/FlappyBirdX.app

✨ 特點

  • 原生 macOS App（非瀏覽器）
  • 無廣告、無追蹤、無後台服務
  • 自動處理 Gatekeeper / Quarantine
  • 即裝即玩

🎮 操作方式

  • 空白鍵：拍動 / 上升
  • Esc：重新開始
  • 關閉視窗即可退出

🔐 安全說明

本程式為個人專案，未使用任何網路連線、資料收集或第三方服務。
原始碼與安裝腳本完全公開，可自行檢視。
